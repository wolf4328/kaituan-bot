# 開團排程機器人

Discord 固定團約時間用的機器人：發時間表讓大家勾可以的日子 → 截止後私訊開團人排程清單 → 確認後自動貼場次卡、開討論串、開打前提醒。

## 安裝（Ubuntu 主機）

1. 在 Supabase 的 SQL Editor 執行 `sql/schema.sql`
2. 在主機上：
   ```
   git clone https://github.com/wolf4328/kaituan-bot.git
   cd kaituan-bot
   bash install.sh
   ```
   依序貼上 Discord Token、Supabase Project URL、service_role 金鑰。

更新到最新版：`bash ~/kaituan-bot/update.sh`
查看紀錄：`sudo journalctl -u kaituan-bot -f`

## 第一次在 Discord 設定

1. `/設定` → 開團頻道
2. `/開團 發起 遊戲:遊戲名稱` → 在面板勾團員、成團條件、日期 → 送出

新遊戲直接打名字就會自動建立，封面會自動用名稱到 Steam 找，找不到就產生一張漸層色封面。團員和規則會記住，下次同款遊戲自動帶入。

## 指令

| 指令 | 誰看得到 | 說明 |
|---|---|---|
| `/月曆 [月份]` | 所有人 | 開團月曆圖（只有自己看得到） |
| `/我的場次` | 所有人 | 自己接下來參加的場次 |
| `/開團 發起 遊戲:名稱 [封面:Steam網址]` | 管理員 | 一次設定團員、條件、日期並發出時間表 |
| `/開團 修改／催填／排程／作廢` | 管理員 | 投票與排程 |
| `/場次 直接開／改時間／取消` | 管理員 | 調整場次 |
| `/遊戲 編輯／刪除` | 管理員 | 改遊戲名稱、規則、封面 |
| `/設定` | 管理員 | 設定面板：頻道、管理員身分組、預設時間、提醒、遊戲列表 |

管理指令預設只有「管理伺服器」權限的人看得到。要開放給其他身分組：伺服器設定 → 整合 → 開團排程機器人。
